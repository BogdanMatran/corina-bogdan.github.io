# Journey Photos

Add your travel photos here for the Journey Map section!

## How to add photos:

1. Place your photos in this folder with these names:
   - `zurich.jpg` - Where you met in Switzerland
   - `romania.jpg` - First trip to Romania
   - `france.jpg` - France adventure
   - `bali.jpg` - Bali trip
   - `miami.jpg` - Miami proposal
   - `bahamas.jpg` - Bahamas celebration
   - `italy.jpg` - Wedding location

2. Update `src/data/storyContent.js` to reference these images:
   ```javascript
   image: '/journey/zurich.jpg'
   ```

3. Photos work best as **square** images (1:1 ratio, e.g., 800x800px)

4. Keep file sizes under 500KB for best performance

## Supported formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

If you don't add photos, the section will display emoji placeholders instead!
